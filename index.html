Français · Русский

Cette page réunit les sources citées dans le film, partie par partie : dictionnaires, éditions, pages, études modernes. Chaque écran du film porte une étiquette — DOCUMENT, CALCUL, NOTRE LECTURE ou HYPOTHÈSE.

Les mots nakhs sont donnés d'après le dictionnaire étymologique d'A. D. Vagapov (2011), les mots germaniques d'après celui de G. Kroonen (2013). Quelques références sont citées d'après un autre auteur ; c'est alors indiqué (« cité par »). Les objections et les avis contraires sont nommés eux aussi. Toutes ces sources sont publiques. Vérifiez-les. Et continuez.
